# -Number-Guessing-Game-
A browser-based number guessing game built with vanilla JavaScript, HTML, and CSS.


How it works
The game generates a secret random number between 1 and 20. The player has 20 attempts to guess it. After each guess, the game gives a hint indicating whether the guess was too high or too low. The score decreases by 1 with every wrong guess. If the player guesses correctly, the background turns green and the highscore is updated if beaten. The game can be reset at any time with the "Again" button, which generates a new secret number while keeping the highscore.
